**① 降级**（含义："缺这项能力、知情接受"）、**② 豁免集**（当次全量 + 每条理由/加入人/时间）、**③ 决策队列**（含年龄、可默认类的结案状态、轻量档与档 0 比例）、**④ 三段配比 + 每周机制复查结论（含"本周无候选"）**、**⑤ 证据质量与前提绑定**（未知前提获 PASS 数、干净重放差异率、交叉越界数、豁免命中活跃租约数 —— 含义是"证据不可靠 ⇒ 停下修证据"，**必须与 ① 分开**）。

理由：这套系统整体是"禁止与登记"，**这五节是唯一能发现"机制本身正在退化"的窗口**；它们若消失，这套东西就退化成新的"文档承诺"。
