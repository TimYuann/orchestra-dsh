## 1. F1：在本部署里"换模型"这个前提不成立，改成"换会话"，缺口如实登记

**你们的依据我们认可**（两处结构缺陷由异质模型发现、同族审查漏掉），机制上也讲得通。**但本部署的事实是**：

- 任意时刻只有一个主力模型；DSH **原生不接 OpenAI**（那条路要 API key，我们是登录式授权）；
- 实际可用的是 DeepSeek 系列；MiniMax M3 时有时无，且**质量不足以承担设计级审查**。

⇒ "设计审查者必须换模型"这条在本部署里**永远落在降级**。按你们的规则一，一条永远降级的要求就是**死要求**，不该写进文档。

**改成 F1'（可实现、可机械判定）**：

1. **设计门必须由独立会话作出**——fresh context，且**不是设计者本人**；
2. **记录设计者与审查者各自的 session id 与 model id**（零成本，便于将来复盘"某类返工是否与模型相关"）；
3. **当部署里存在第二个可用模型时优先用它**：满足记 `satisfied`，不存在记 `degraded`、**不阻塞**；
4. 普通实现审查**不强制**（保持你们的边界）。

**一条必须并列写进"不得声称"**：**换会话 ≠ 换模型。** 独立会话买到的是"没有作者的上下文污染"，买不到"不同的先验"；我们不会把前者说成后者。

**顺带一个与模型无关的现场证据，支持第 1 条**：上一轮 E2E 里 `difficulty-reviewer` **从头到尾是 `reserved`、从未物化**——那条车道的设计**根本没有被独立审查过**。所以"设计门必须由独立会话作出"本身就有价值，不是形式。

**落点**：P2（随节点记录一起落地）。

## 3. 预设落点：Owner 已定 B；并更正一处事实

- **结论：私有根 + `trust: system`** —— 目录 `~/.dsh/orchestra/catalog-presets`；配置里路径用 `~` 开头（已核实发现过程会做 `expandHomePath`）。
- **事实更正**：你们建议"用实验区分 A/B"——**那个实验区分不了**。A 与 B 都能让 DSH 解析出 id（我们实测：把插件目录当作根时 **12/12 健康**）；"重启后是否保住身份"取决于**恢复路径有没有执行挂载动作**（一处代码修复，两种落点完全一样）。**N7 照做**，但它验的是那处修复，不是落点。
- **选 B 的真实理由**：**归属与可写性**——名册的用户根是 DSH 的"可写根"（UI 可从那里复制/删除预设），而 `trust: system` 的私有根**不会被当作可写根**，插件成为唯一所有者（可见性我们尚未逐个验证，不作承诺）。
